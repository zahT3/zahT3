# Insight relay

A chain of riddles on this profile. Each layer is written by the person who solved the one before it.

1. Read the current riddle on the [profile](https://github.com/zahT3).
2. [Open an answer issue](https://github.com/zahT3/zahT3/issues/new?template=answer.yml). A bot replies within a minute and closes it. Case, spaces and punctuation are ignored. Try as often as you like.
3. If you are right, the bot sends you a link to the [setter page](https://zahT3.github.io/zahT3/). Write the next riddle, its answer, and an optional message for the next solver. The page hashes your answer in your browser; only the hash is published.
4. @zahT3 reviews each new layer before it goes live, then the chain continues.

Ground rules: plain text only, riddle up to 280 characters, message up to 140. No links, ads, personal data or anything you would not show a stranger. A riddle should be solvable by thinking, not by asking a search engine or a chatbot.

Answers you submit are public. Answers are stored as salted PBKDF2-SHA256 hashes (200,000 iterations), so a short dictionary word can still be guessed offline: prefer answers that are hard to guess without solving the riddle.
